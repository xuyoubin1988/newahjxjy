# 安徽继续教育在线新平台助手使用说明

## 1. 功能简介

本脚本用于安徽继续教育在线新平台的学习辅助，主要包含：

- 课程队列选择与自动顺序处理
- 章节学习进度提交
- 作业自动处理（可在面板中开启/关闭）
- 人脸采集弹窗（支持拍照上传与基础预检）
- 云端授权（免费体验 / Pro Token）
- 考试辅助面板（**仅 Pro**，仅在考试页面生效）
- 支持效率模式和1:1时长安全模式自由切换

## 2. 首次使用流程

1. 先在平台网页正常登录（`https://jxjynew.ahjxjy.cn/`）
2. 刷新页面，等待右侧脚本面板出现
3. 先点击“采集人脸照”，完成一次手动拍照上传
4. 在课程页勾选要学习的课程队列
5. 点击“开始”

## 3. 面板说明

- **Token 输入框**：用于填写 Pro 授权 Token
- **保存并校验**：保存 Token 并向云端校验
- **用户类型**：显示当前是 `free` 还是 `pro`
- **免费体验章节**：显示免费额度使用情况（Pro 显示不限）
- **课程卡片信息**：课时进度 / 作业 / 考试
- **作业：开/关**：是否自动处理作业
- **考试辅助：开/关**：是否启用考试辅助（**仅 Pro 可用**）
- **AI搜题：开/关**：仅在设置页中生效，**仅 Pro 可用**

## 4. 免费 / Pro 机制说明

- 未填 Token 时默认按免费档运行
- 免费档会有章节体验额度限制
- 填写有效 Token 并校验成功后显示 Pro，不受免费体验额度限制
- 考试辅助功能仅 Pro 可使用
- AI 搜题功能也仅 Pro 可用

### 开通 Pro

1. 公测期间（截至 4 月 25 日）：联系群管理获取 Token
2. 其他时间：扫码购买获取 Token
3. 将 Token 粘贴到面板输入框，点击“保存并校验”

> Token 请勿泄露，避免多人共用导致失效。

## 5. 人脸采集注意事项

- 拍照前尽量保证单人入镜、正脸、光线充足
- 脚本已增加本地预检（支持浏览器会检测 0 脸/多脸/过小/过偏）
- 预检不通过会提示重拍，不会继续上传
- 若平台提示 **“三次人脸核验失败，请明日再试”**：脚本会自动识别并在当天停止继续尝试

## 6. 考试辅助（仅 Pro）

### 6.1 入口与生效范围

- 只在考试页面下显示“考试辅助面板”（前提：**Pro + 考试辅助开**）

### 6.2 功能点

- **题卡+详情**：显示题号、题型、题目、题库答案
- **题库答案 / AI答案分开显示**：只有题库缺失（或当前答案来自 AI）时才显示 AI 答案区域
- **主观题复制**：仅填空/简答/问答/论述等主观题提供“复制”按钮
- **题库收录**：题库没有答案时，多次重做/提交过程中会逐步收录到云端题库

### 6.3 重要提示

- 建议 **每题提交间隔 3–5 秒**，过快可能触发“操作频繁”导致提交失败
- 交卷成功后会缓存题到题库（下次可直接使用）

## 7. AI 搜题（仅 Pro）

### 7.1 开关与触发
- 面板“设置”中有 `AI搜题：开/关`
- **仅 Pro 用户可用**：非 Pro 时不会触发 AI 搜题请求
- AI 触发条件：当题库答案缺失（或当前答案来自 AI）时，才会调用 AI 去补全

### 7.2 AI 答案展示与复制规则
- 考试辅助面板把答案分成两个区域：
  - **题库答案**：云端/平台题库返回
  - **AI答案**：AI 生成


## 8. 常见问题（FAQ）

### Q1：点击开始没反应或提示云端失败？

- 检查网络是否可访问云端授权地址
- 有 Token 时先点一次“保存并校验”
- 仍失败可先清空 Token 按免费档测试

### Q2：为什么显示免费额度已用完？

- 免费档达到章节上限后会提示升级 Pro
- 填写有效 Token 并校验成功后可继续

### Q3：作业不想自动做怎么办？

- 面板点击“作业：开/关”切到关闭即可

### Q4：考试辅助不显示？

- 确认 **用户类型为 Pro**
- 确认主面板里 **“考试辅助：开”**
- 确认当前在考试页面 `#/myExam/...`

### Q5：如何停止？

- 点击“停止”按钮，脚本会在当前步骤结束后退出
